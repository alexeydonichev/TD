# Долина Разлома

Оригинальный браузерный vertical slice Tower Defense: одна законченная карта, четыре башни, управляемый герой, 20 волн и три босса.

После первого успешного GitHub Pages workflow игра доступна по адресу: <https://alexeydonichev.github.io/TD/>.

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте `http://127.0.0.1:4173`.

## Проверки

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm test:e2e
pnpm build
pnpm preview
```

## Управление

- ЛКМ — строительство и выбор башни
- `WASD` — точное ручное движение Стража Грозы
- ПКМ по земле — идти к точке; ПКМ по врагу — удерживать фокус-цель
- `C` — переключение «Охраны» (держать позицию) и «Погони» (сближаться с фокусом)
- `1`–`4` — выбор башни
- `Q/Shift/E/R` — способности героя; `Q` предпочитает фокус, а рывок идёт по `WASD`, к фокусу или курсору
- Стрелки или средняя кнопка мыши — камера
- Колесо или кнопки `− / +` — плавный масштаб
- `Space` — пауза, `F` — камера на герое, `Esc` — отмена строительства

## Режимы и доступность

- «Хранитель», «Защитник» и «Повелитель бури» меняют не только врагов и экономику, но и темп между волнами, силу/риск героя, возрождение, щиты боссов и цену раннего старта. Все правила видны до начала матча.
- Встроенное обучение проводит через строительство, запуск волны, героя, способности и улучшение.
- Тактический брифинг показывает точный состав каждой волны, награду и текущий бонус раннего старта.
- Инспектор выбранной башни показывает эффективные характеристики, нанесённый урон, убийства и охват ауры поддержки.
- Настройки включают высокую контрастность, крупный HUD, уменьшение движения, отключение встряски, музыки и эффектов.

## Производительность

```bash
pnpm profile:80
pnpm proof:balance
pnpm proof:control
pnpm check:bundle
```

Phaser и сцена загружаются динамически только после старта матча. Performance gate создаёт 100 активных противников и проверяет FPS, число игровых объектов и ошибки консоли.

Все игровые ассеты созданы специально для проекта. Сторонние игровые ассеты не используются; происхождение и карта атласов описаны в `docs/art-direction.md`.
