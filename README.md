# Долина Разлома

Оригинальный браузерный vertical slice Tower Defense: одна законченная карта, четыре башни, управляемый герой, 10 волн и финальный босс.

После первого успешного GitHub Pages workflow игра доступна по адресу: <https://alexeydonichev.github.io/TD/>.

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте `http://127.0.0.1:4173`.

## Проверки

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm test:e2e
pnpm build
pnpm preview
```

## Управление

- ЛКМ — строительство и выбор башни
- ПКМ — движение Стража Грозы
- `1`–`4` — выбор башни
- `Q/W/E/R` — способности героя
- `WASD` — камера, колесо — масштаб
- `Space` — пауза, `F` — камера на герое, `Esc` — отмена строительства

Игра и все временные векторные ассеты созданы для этого прототипа. Сторонние игровые ассеты не используются.
