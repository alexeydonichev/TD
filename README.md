# Долина Разлома

Оригинальная браузерная Tower Defense-кампания: пять законченных карт с разными маршрутами и темпом экономики, четыре башни, управляемый герой с развитием до 10-го уровня, 20 волн и три босса на каждой карте.

После первого успешного GitHub Pages workflow игра доступна по адресу: <https://alexeydonichev.github.io/TD/>.

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте `http://127.0.0.1:4173`.

## Проверки

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm test:e2e
pnpm build
pnpm preview
```

## Управление

- ЛКМ — строительство и выбор башни
- При выборе башни карта показывает допустимые ячейки 50×50; установка автоматически привязана к сетке
- `WASD` — точное ручное движение Стража Грозы
- ПКМ по земле — идти к точке; ПКМ по врагу — удерживать фокус-цель
- `C` — переключение «Охраны» (держать позицию) и «Погони» (сближаться с фокусом)
- `X` — отменить прицел/приказ, очистить фокус и немедленно держать позицию
- `1`–`4` — выбор башни
- `U` — улучшить выбранную башню
- `Q/Shift/E/R` — способности героя; `Q` предпочитает фокус, рывок идёт по `WASD`, к фокусу или курсору
- `R`, затем ЛКМ по карте — подтвердить зону бури; ПКМ, `Esc` или повторное `R` — отменить без затрат
- Стрелки или средняя кнопка мыши — камера
- Колесо или кнопки `− / +` — плавный масштаб
- `Space` — пауза, `F` — камера на герое, `Esc` — отмена строительства

## Режимы и доступность

- Кампания включает «Долину Разлома», «Ледяной перевал», «Пепельный бастион», «Грозовой шпиль» и «Сердце Бездны». Все карты видны и доступны на стартовом экране; после победы кнопка ведёт на следующую.
- Опыт героя сбрасывается при переходе на новую карту: награда за 20 завершённых волн гарантирует 8-й уровень, а 9–10-й требуют личных атак по врагам, элите и боссам. Каждый уровень усиливает здоровье, ману, базовую атаку и четыре умения.
- В HUD встроен динамический справочник навыков с текущими уроном, числом целей, длительностью, радиусом, стоимостью и перезарядкой. Q накладывает Проводимость и усиливает последующий R на 25%; Shift телепортирует героя сквозь врагов и даёт 1,2 секунды неуязвимости; E одновременно защищает героя и повышает урон башен в ауре на 35%.
- «Хранитель», «Защитник» и «Повелитель бури» меняют не только врагов и экономику, но и темп между волнами, силу/риск героя, возрождение, щиты боссов и цену раннего старта. Все правила видны до начала матча.
- Встроенное обучение проводит через строительство, запуск волны, героя, способности и улучшение.
- Тактический брифинг показывает точный состав каждой волны, награду и текущий бонус раннего старта.
- Инспектор выбранной башни показывает эффективные характеристики, нанесённый урон, убийства и охват ауры поддержки.
- Полнофигурный спрайт героя, линии приказов, кольца стоек, прицельные зоны, руны маршрута и вспышки попаданий улучшают читаемость боя.
- Настройки включают высокую контрастность, крупный HUD, уменьшение движения, отключение встряски, музыки и эффектов.

## Производительность

```bash
pnpm profile:80
pnpm proof:balance
pnpm proof:control
pnpm proof:rift
pnpm check:bundle
```

Phaser и сцена загружаются динамически; фон выбранной карты — единственный фон кампании, который скачивается при старте матча. Загрузка показывает реальный прогресс, ограничена тайм-аутом и предлагает безопасный повтор при сетевой ошибке. Performance gate создаёт 100 активных противников и проверяет FPS, число игровых объектов и ошибки консоли.

Все игровые ассеты созданы специально для проекта. Сторонние игровые ассеты не используются; происхождение и карта атласов описаны в `docs/art-direction.md`.
